SceneFrom3D

Geometry-Conditioned Outdoor 3D Scene Generation via View Scheduling with Object-Level Control

Geonung Kim, Jeongeun Park, Nuri Ryu, Di Liu, Sunghyun Cho

arXiv, 2026

Paper Code

Abstract

SceneFrom3D is a framework for geometry-conditioned outdoor 3D scene generation. Given coarse or fine object geometries with per-object appearance and geometry-adherence controls, SceneFrom3D generates a 3DGS scene that can be rendered and explored from arbitrary viewpoints.
